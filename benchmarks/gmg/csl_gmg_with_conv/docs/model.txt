Let B = blockSize, C = cost of passing one PE, z = size of zdim, d = distance between two active PEs.
At level L, d = 2^L and z = z0/2^L


The cost of communication = Memory to router(T1) + source to dest (T2) + router to memory (T3)

at level L =  (B + C*d) * (z/B)

At level L+1, d -> 2*d and z -> z/2, so
The cost of communication at level L+1 =  (B + C*(2*d)) * ((z/2)/B) = (B/2 + C*d) * (z/B)  is smaller than cost at level L.
The difference is (B/2)*(z/B) = z/2 = z0/2^(L+1).
So the difference is shrinking as L increases.
